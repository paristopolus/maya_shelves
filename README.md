These are a collection of tools for Maya that simplify much of the workflow for quick and dirty hard surface rigging. 
Students of the ANIM321 course on Rigging and Animation, please download the ANIM321 shelf and place it into your Maya workspace:
C:\Users\<Your School User Name or Home Computer User name>\Documents\maya\<Version of Maya>\prefs\shelves

Download by right-clicking the shelf and choose "save link as".
